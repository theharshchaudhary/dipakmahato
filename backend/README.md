# Backend

Laravel 12 API and Filament 4 admin panel for the site. See the [root README](../README.md)
for setup, deployment and how the pieces fit together.

- `app/Http/Controllers/Api` — public, read-only content API and the contact endpoint
- `app/Filament` — admin panel (pages, essays, ventures, messages, settings)
- `database/seeders/ContentSeeder.php` — initial site content
